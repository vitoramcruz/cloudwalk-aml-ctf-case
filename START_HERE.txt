Two ways to view this dashboard:

1) INSTANT PREVIEW (no install) -> open dashboard_click_to_open.html
   directly in any web browser (double-click it). This is a static
   snapshot with the real computed numbers embedded, in English.

2) FULL INTERACTIVE APP (upload new files, drill-down, live simulator):

   python3 -m venv .venv
   source .venv/bin/activate          (Windows: .venv\Scripts\activate)
   pip install -r requirements.txt
   streamlit run app.py

   The browser opens automatically at http://localhost:8501
   Upload the AML workbook (.xlsx) in the sidebar.
